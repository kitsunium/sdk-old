# Coverage Requirements for Kernel Packages

## Purpose

Define and enforce comprehensive test coverage requirements to ensure kernel packages meet the 95% minimum coverage target with justified exceptions.

## Coverage Targets

### Minimum Requirements

- **Overall Package**: 95% minimum
- **Exported Functions**: 100% required
- **Critical Paths**: 100% required
- **Error Handling**: 100% required
- **Safe Implementation**: 95% minimum
- **Unsafe Implementation**: 90% minimum (with justification)

## Measuring Coverage

### Basic Coverage Commands

```bash
# Package coverage
go test -cover ./pkg/kernel/foo

# Detailed coverage with profile
go test -coverprofile=coverage.out ./pkg/kernel/foo
go tool cover -html=coverage.out

# Coverage by function
go tool cover -func=coverage.out

# Multiple packages
go test -cover ./pkg/kernel/...
```

### Coverage Analysis Script

```bash
#!/bin/bash
# coverage.sh

PACKAGE=$1
THRESHOLD=${2:-95.0}

# Run tests with coverage
go test -coverprofile=coverage.out ./${PACKAGE}

# Extract coverage percentage
COVERAGE=$(go tool cover -func=coverage.out | grep total | awk '{print $3}' | sed 's/%//')

# Check threshold
if (( $(echo "$COVERAGE < $THRESHOLD" | bc -l) )); then
    echo "FAIL: Coverage ${COVERAGE}% is below ${THRESHOLD}% threshold"
    exit 1
else
    echo "PASS: Coverage ${COVERAGE}% meets threshold"
fi

# Generate HTML report
go tool cover -html=coverage.out -o coverage.html
echo "Coverage report: coverage.html"
```

## Coverage Enforcement

### CI/CD Integration

```yaml
# .github/workflows/test.yml
name: Tests
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-go@v4
        with:
          go-version: '1.21'

      - name: Run tests with coverage
        run: |
          go test -race -coverprofile=coverage.out -covermode=atomic ./...

      - name: Check coverage threshold
        run: |
          COVERAGE=$(go tool cover -func=coverage.out | grep total | awk '{print $3}' | sed 's/%//')
          echo "Coverage: ${COVERAGE}%"
          if (( $(echo "$COVERAGE < 95.0" | bc -l) )); then
            echo "Coverage below 95% threshold"
            exit 1
          fi

      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage.out
```

### Pre-commit Hook

```bash
#!/bin/sh
# .git/hooks/pre-commit

# Check coverage before commit
COVERAGE=$(go test -cover ./... 2>&1 | grep -oP '\d+\.\d+(?=%)')

for pkg_coverage in $COVERAGE; do
    if (( $(echo "$pkg_coverage < 95.0" | bc -l) )); then
        echo "Error: Package coverage $pkg_coverage% below 95% minimum"
        exit 1
    fi
done

echo "All packages meet coverage requirements"
```

## Justified Exclusions

### Acceptable Exclusions

```go
// Panic recovery (defensive, should never execute)
//go:build !coverage
func recoverFromPanic() {
    if r := recover(); r != nil {
        // Defensive code - excluded from coverage
        log.Fatal("unexpected panic:", r)
    }
}

// Platform-specific implementations
//go:build windows && !coverage
func windowsSpecific() {
    // Windows-only code tested separately
}

// Generated code
// Code generated by "go generate"; DO NOT EDIT.
// Coverage: excluded

// Unreachable defensive code
func validateInvariant(x int) {
    if x < 0 {
        // This should never happen due to caller validation
        // Coverage: excluded (defensive)
        panic("invariant violation")
    }
}
```

## Improving Coverage

### Identifying Gaps

```bash
# Find uncovered lines
go tool cover -func=coverage.out | grep -E "^.*\s+0\.0%$"

# Generate annotated source
go tool cover -html=coverage.out -o coverage.html
# Open coverage.html and look for red lines
```

### Common Coverage Gaps

#### Error Paths

```go
// Before: Uncovered error path
func Process(data []byte) error {
    if len(data) == 0 {
        return errors.New("empty data") // Often uncovered
    }
    // Process...
}

// After: Test error paths explicitly
func TestProcess_ErrorCases(t *testing.T) {
    tests := []struct {
        name    string
        input   []byte
        wantErr string
    }{
        {"empty data", []byte{}, "empty data"},
        {"nil data", nil, "empty data"},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            err := Process(tt.input)
            assert.EqualError(t, err, tt.wantErr)
        })
    }
}
```

#### Concurrent Code

```go
// Ensure concurrent paths are covered
func TestConcurrentPaths(t *testing.T) {
    buf := NewWidget(1024)

    // Force both lock acquisition paths
    var wg sync.WaitGroup
    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            buf.Write([]byte("test"))
        }()
    }
    wg.Wait()
}
```

## Coverage Best Practices

### 1. Test Organization for Coverage

```go
// Group tests by coverage area
func TestWidget_CoreOperations(t *testing.T) {
    // Tests that cover main functionality
}

func TestWidget_ErrorHandling(t *testing.T) {
    // Tests that cover all error paths
}

func TestWidget_EdgeCases(t *testing.T) {
    // Tests that cover boundary conditions
}

func TestWidget_Concurrency(t *testing.T) {
    // Tests that cover concurrent access
}
```

### 2. Coverage-Driven Development

```go
// Write test first to ensure coverage
func TestNewFeature(t *testing.T) {
    // Define expected behavior
    result := NewFeature(input)
    assert.Equal(t, expected, result)
}

// Then implement to make test pass
func NewFeature(input string) string {
    // Implementation that satisfies test
}
```

### 3. Mutation Testing

```go
// Verify tests actually test behavior
func TestWidgetWrite_DetectsErrors(t *testing.T) {
    buf := NewWidget(10)

    // This test should fail if we remove bounds check
    _, err := buf.Write(make([]byte, 20))
    assert.Error(t, err)

    // Manually verify: comment out bounds check and ensure test fails
}
```

## Coverage Reports

### HTML Report Features

- **Red lines**: Uncovered code
- **Yellow lines**: Partially covered (some branches missed)
- **Green lines**: Fully covered
- **Gray lines**: Non-executable (comments, declarations)

### Coverage Metrics

```go
// coverage_test.go
func TestCoverageMetrics(t *testing.T) {
    cmd := exec.Command("go", "test", "-cover", "./...")
    output, _ := cmd.Output()

    // Parse and display metrics
    lines := strings.Split(string(output), "\n")
    for _, line := range lines {
        if strings.Contains(line, "coverage:") {
            fmt.Println(line)

            // Extract percentage
            re := regexp.MustCompile(`(\d+\.\d+)%`)
            matches := re.FindStringSubmatch(line)
            if len(matches) > 1 {
                coverage, _ := strconv.ParseFloat(matches[1], 64)
                if coverage < 95.0 {
                    t.Errorf("Package coverage %.1f%% below 95%%", coverage)
                }
            }
        }
    }
}
```

## Do's and Don'ts

### Do's

- ✅ Measure coverage regularly
- ✅ Document exclusion reasons
- ✅ Test error paths explicitly
- ✅ Use coverage to find missing tests
- ✅ Enforce coverage in CI/CD
- ✅ Review coverage reports in PRs

### Don'ts

- ❌ Don't exclude code without justification
- ❌ Don't write meaningless tests for coverage
- ❌ Don't ignore coverage warnings
- ❌ Don't merge PRs that reduce coverage
- ❌ Don't test implementation details
